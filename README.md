# Paralympic-Participation-Performance-Power-BI-Dashboard
An interactive Power BI dashboard analyzing historical Paralympic participation, top-performing nations, medal distributions, seasonal trends, and sport-wise performance.
Paralympic Participation & Performance Dashboard
Project Overview
This repository contains a comprehensive, interactive Power BI dashboard tracking historical data from the Paralympic Games. The dashboard provides end-to-end insights into medal distributions, participating nations, seasonal variations (Summer vs. Winter), and sport-level breakdowns. 


Key Features & Visualizations
•	Key Performance Indicators (KPIs): Instant view of Total Medals, Gold/Silver/Bronze Victories, and Total Participating Nations. 

•	Top 10 Nations Ranking: Stacked bar chart highlighting top-performing countries ranked by total medal count. 

•	Historical Trends: Line chart visualizing medal trends over time across different game seasons. 

•	Summer vs. Winter Distribution: Donut chart displaying the proportion of medals contested across game seasons. 

•	Sport Discipline Breakdown: Clustered column chart detailing medal totals across top sports disciplines. 

•	Interactive Slicers: Dynamic filtering by Game Season (Summer/Winter) and Paralympic Year with a single-click slicer reset option. 

Data Source & Architecture
•	Dataset: Paralympics Dataset cleaned.xlsx


•	Tool Stack: Microsoft Power BI Desktop, DAX, Custom UI Canvas Layout
